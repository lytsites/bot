TG Web Auth: карта интерфейса для AI-поддержки (актуально по текущему коду)

1) Глобальная структура
- После входа отображается "Панель управления".
- Верхние вкладки:
  - "Главная"
  - "Мониторинг"
  - "Настройки"
- На мобильных верхние вкладки могут отображаться как select.
- Есть служебные модальные окна:
  - Блокирующая модалка "Нет интернет-соединения" / "ИИ недоступен".
  - Модалка "Требуется переавторизация Telegram".
  - Модалка добавления Telegram-аккаунта (QR).
  - Модалка найденных сообщений по группе.
  - Разовая модалка о новой линии поддержки.
- В левом нижнем углу есть плавающая кнопка "Поддержка", открывает окно поддержки.

2) Главная
Левая поднавигация:
- "Чтение групп" (если включен feature_group_reading_enabled)
- "Авто. диалоги" (если включен feature_auto_dialogs_enabled)

2.1) Главная -> Чтение групп
- Заголовок: "Чтение групп"
- Кнопка: "Обновить"
- Показывается список групп Telegram:
  - Название
  - ID группы
  - статус LISTENING/OFF
- При выборе группы справа блок "Группа":
  - переключатель "Слушать"
  - если группа слушается: счетчик найденных сообщений + кнопка "Показать"
- Кнопка "Показать" открывает модалку "Найденные сообщения" с историей матчей.

2.2) Главная -> Авто. диалоги
- Режим списка:
  - Заголовок: "Авто. диалоги"
  - Пилюля "Активно: X/Y"
  - Кнопка "Запустить (N)" для выбранных контактов
  - Список юзернеймов/контактов с состояниями диалога
- Режим конкретного диалога:
  - Кнопка "Назад"
  - Статус (Запуск/Ждет ответ/Активен/Остановлен/Ошибка)
  - Кнопки "Остановить" / "Запустить"
  - История сообщений отображается в ChatThread.

3) Мониторинг
Левая поднавигация:
- "История чтения групп" (если доступна функция чтения групп)
- "История авто. диалогов" (если доступна функция авто-диалогов)
- "История реквизитов"
- Для admin:
  - "Аккаунты"
  - "История воркеров"
- Для superadmin:
  - "Инциденты"

3.1) Мониторинг -> История чтения групп
- Кнопка "Обновить"
- Для админов может быть переключатель scope:
  - "Личные"
  - "Общие"
- Пагинация: "Назад", "Дальше", "Сдвиг", "Лимит"
- История сообщений с подсветкой ключевых слов.

3.2) Мониторинг -> История авто. диалогов
- Кнопка "Обновить"
- Для админов может быть переключатель scope "Личные/Общие"
- Список диалогов с их статусами.
- При открытии диалога показывается история чата (ChatThread).

3.3) Мониторинг -> История реквизитов
- Кнопка "Обновить"
- Для админов может быть переключатель scope "Личные/Общие"
- Список найденных реквизитов:
  - значение
  - тип (Телефон/Банковская карта/IBAN/Неопознанный)
  - страна (Казахстан/СНГ/Зарубеж/Не определено)
  - дополнительный контекст (username/phone/chat/dialog/message/time)

3.4) Мониторинг -> Аккаунты (admin)
- Управление локальными пользователями и их правами/доступами.
- Изменение роли и флагов функций сервиса.
- История входов пользователя.
- Операции удаления локального пользователя и Telegram-аккаунтов.

3.5) Мониторинг -> История воркеров (admin)
- Таблица запусков воркеров:
  - ID, аккаунт, статус, период, ошибка.

3.6) Мониторинг -> Инциденты (superadmin)
- Унифицированный поток инцидентов:
  - events/errors
  - failed jobs
  - ошибки group_worker_runs
  - ошибки auto_chat_dialogs
  - ошибки auth_flows
  - эскалированные support_tickets
- Колонки:
  - Когда, Уровень, Источник, Локальный, Аккаунт, Описание.

4) Настройки
Левая поднавигация:
- "Основные"
- "Аккаунты"
- "Чтение групп" (если feature включена)
- "Авто. диалоги" (если feature включена)

4.1) Настройки -> Основные
- Переключатель "Темная тема".

4.2) Настройки -> Аккаунты
- Блок "Telegram" с кнопкой "Добавить аккаунт TG".
- Список Telegram-аккаунтов пользователя:
  - display_name / phone
  - статус ACTIVE/INACTIVE
- Действия:
  - "Переключиться"
  - "Удалить аккаунт"
  - "Удалить все"

4.3) Настройки -> Чтение групп
- Поле "Ключевые слова (через запятую)"
- Переключатель "Активно"
- Кнопка "Сохранить"

4.4) Настройки -> Авто. диалоги
- Управление списком Telegram-юзернеймов:
  - ввод (по одному в строке)
  - "Сохранить"
  - "Удалить выбранные"
  - "Удалить все"
- Блок "Имитации":
  - задержка перед ответом (от/до)
  - имитация печатания
  - имитация прочтения
- Поле "Инструкция для ИИ (роль, стиль, ограничения)"
- Поле "Примеры приветствий и первых сообщений"
- Кнопка "Сохранить"

5) Поддержка (виджет в левом нижнем углу)
- Плавающая кнопка "Поддержка".
- Окно поддержки:
  - Заголовок "Техподдержка"
  - Режимы: список / новое обращение / чат
  - В режиме списка:
    - "Новое обращение"
    - "Обновить"
    - список обращений (тема, дата/время, статус)
  - В режиме нового обращения:
    - поле "Тема"
    - поле "Сообщение"
    - кнопка "Отправить"
  - В режиме чата:
    - по центру тема обращения
    - мини-чат (сообщения USER/ASSISTANT/SYSTEM)
    - поле ввода + "Отправить"
    - кнопка "Решено"
    - для эскалированных/закрытых обращений чат закрыт на отправку.

6) Логика поддержки (backend)
- При создании обращения AI принимает решение:
  - self_answer: открыть чат и ответить в системе
  - escalate: передать обращение в поддержку
- Эскалированные обращения:
  - отправляются в Telegram support-боту/каналу через серверный notify
  - попадают в "Мониторинг -> Инциденты" как source=support_tickets.

7) Роли и ограничения
- user: только свои данные и личная область.
- admin: доступ к расширенным разделам мониторинга (аккаунты, воркеры), scope общий/личный.
- superadmin: дополнительно раздел "Инциденты".
- Ограничения feature:
  - feature_group_reading_enabled
  - feature_auto_dialogs_enabled
  - service_enabled (полное отключение возможностей).

8) Как отвечать пользователю по навигации
- Использовать реальное название вкладок/подвкладок как в UI выше.
- Давать путь в формате:
  - "Откройте: Настройки -> Аккаунты -> ..."
  - "Откройте: Мониторинг -> История авто. диалогов -> ..."
- Если у пользователя не хватает роли/фичи, явно говорить, какая роль/флаг нужен.
